## 🚀 Sobre o Projeto

Este é o meu portfólio oficial, desenvolvido para apresentar meus projetos, habilidades técnicas e serviços de desenvolvimento web. O design foi construído com estética dark minimalista, detalhes dourados e animações fluidas para transmitir sofisticação e profissionalismo.

### ✨ Funcionalidades
- **Design 100% Responsivo:** Adaptado com precisão para computadores, tablets e smartphones.
- **Efeitos Visuais Exclusivos:** Partículas de fundo, linha de luz dourada interativa e animações de revelação por rolagem (*Scroll Reveal*).
- **Catálogo de Serviços Interativo:** Modais dinâmicos detalhando cada modalidade de serviço com atalho para solicitação via WhatsApp.
- **Seção de Contato Rápido:** Balão de visualização e cópia instantânea de e-mail com 1 clique, além de conexões diretas para WhatsApp, Instagram e GitHub.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação moderna focada em acessibilidade e SEO.
- **CSS3 Avançado:** Glassmorphism, animações com keyframes, variáveis CSS e design system modular.
- **JavaScript (ES6+):** Manipulação dinâmica de DOM, animações reativas e integração com Clipboard API.
